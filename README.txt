Jellyfin AI 助手 安装说明
==========================

本软件包含两部分：
  1. 插件（plugin 文件夹）—— 装进 Jellyfin，让网页里多一个「AI 助手」入口
  2. AI 服务（jellyfin-agent.exe）—— 负责和 DeepSeek 对话、控制媒体

===========================================
一、安装插件
===========================================
1. 双击运行「install-plugin.bat」，脚本会自动把插件装进 Jellyfin。
2. 重启 Jellyfin：右下角托盘图标 → 退出，再从开始菜单重新打开。

===========================================
二、启动 AI 服务
===========================================
双击「start-ai-assistant.bat」，会弹出一个黑色窗口。
请保持这个窗口开着（不要关）—— 关掉它 AI 就用不了了。

建议设置开机自启（可选）：
  按 Win+R，输入 shell:startup 回车，
  把「start-ai-assistant.bat」的快捷方式放进打开的文件夹。

===========================================
三、使用
===========================================
1. 浏览器打开 Jellyfin 网页。
2. 左侧主菜单点「AI 助手」。
3. 填 DeepSeek API Key（到 https://platform.deepseek.com 申请）。
4. 想让它控制播放/暂停，再填 Jellyfin API Key
   （Jellyfin 后台 → API 密钥 里生成一个）。
5. 点「保存配置」后就能对话了。

===========================================
四、常见问题
===========================================
- 点「AI 助手」是黑屏 / 空白：
   插件还没生效，重启 Jellyfin 再试。

- 对话时报「连接失败 / HTTP 500」：
   确认 start-ai-assistant.bat 的黑色窗口还开着。

- AI 说「没有活动会话」：
   先在某台设备上开始播放，或填好 Jellyfin API Key。

- 杀毒软件拦截 jellyfin-agent.exe：
   这是打包成的独立程序，属于误报，点「允许」即可。

===========================================
版本要求
===========================================
本插件仅适用于 Jellyfin 12.4 版本。
如果你的 Jellyfin 是其他版本，插件会无法加载。
